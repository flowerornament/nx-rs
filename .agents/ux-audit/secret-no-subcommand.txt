Manage encrypted secrets via sops

Usage: nx secret [OPTIONS] <COMMAND>

Commands:
  add  Add or update a secret key/value

Options:
      --plain    Use plain output formatting
      --unicode  Force Unicode/emoji output
      --minimal  Minimal output (less context)
  -v, --verbose  Verbose output
      --json     JSON output when supported
  -h, --help     Print help (see more with '--help')
